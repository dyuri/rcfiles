# Plain-Language Technical Writing

Write clear, direct, and pragmatic technical content. Avoid corporate buzzwords, flowery adjectives, and overly formal phrasing.

## Core Rules

1. **Keep Sentences Short:** Break complex thoughts into multiple simple sentences. One idea per sentence.
2. **Use Active Voice and Direct Address:** Speak directly to the reader ("you") and use active verbs.
3. **Favor Drafty & Modular Structures:** 
   * Use bullet points and numbered lists for steps or options.
   * Use clear, short headings.
   * Prefer code blocks and configuration snippets over dense paragraphs.
4. **Cut the Fluff:** Remove filler words, marketing speak, and preamble. Get straight to the technical reality.
